# gtv Roadmap

> 修订于 2026-08-18。依据：design-v2.md 的规格、`docs/reference/gmaster-io/` 新入库的
> 官网存档（Branch Explorer 全界面截图、过滤栏形态、右键菜单全量项）、以及在大仓库
> （2000 提交 / 37 泳道）上的实测观察。
>
> 原则：gtv 借鉴 gmaster 的设计词汇，但不复刻它。每个里程碑只对齐"用户价值"，
> 不对齐"原作有没有这个功能"。

## 已完成的地基（2026-03 原型 → 2026-08 重写）

- 泳道传播引擎（first-parent 血缘、tip 保护墙、已合并优先）+ 9 个算法测试
- 智能压缩、时间比例 x 轴、变更量节点大小、迷你图、泳道聚焦
- 吸顶自适应精度时间轴、标签碰撞分层、边交互（高亮/跳转父/跳转子）
- 触摸板手势（双指平移、捏合缩放）、分支面板（搜索/倒序/All/None/双击 solo）
- 非活跃泳道收拢（M1.2，2026-08）：超阈值无活动的泳道沉入痕迹行（已归档/已合
  并、休眠/未合并两组），分支面板分组 + 单条恢复，fork 父链闭包与基座分支保护，
  阈值设置 `gtv_inactive_days`（默认 90 天，可关）；1000+ 分支仓库默认泳道 ≤30
- 提交搜索定位（M1.3，2026-08）：Cmd/Ctrl+F 全史搜索 message/author/hash（已
  加载范围即时匹配 + 防抖后端全史补全、按 id 去重合并），命中行显示 hash +
  subject + author，已加载范围外命中以"从该提交查看"ancestry 跳转居中
- 异常时间间隙折叠（M1.1，2026-08）：超过 45 天的无提交间隙折叠为固定宽度
  断轴（渲染器画断轴标记、刻度尺跳过折叠段）——单个 2038 年式异常时间戳不再
  把时间比例 x 轴拉成 4 万像素空白；纯函数测试钉死
- 规模上限治理（M1.4，2026-08）：revwalk 2000 上限改为显式分页
  （load_older_commits 按块回溯旧史、已加载集保持向下封闭）；diff stats 移出
  打开路径，首屏后异步批量补取（新命令 get_commit_stats）
- 过滤系统补完（M2，2026-08）：右键泳道"只显示相关分支"（血缘闭包 = 单线
  fork 上链 + 子孙 BFS + merge 单跳 + target 级反并，复用既有分支选择重建）、
  顶栏日期范围下拉（周/月/3月/年/自定义，纯前端裁剪 + x 平移，窗口清空的
  泳道沉入痕迹行且面板分组/展开镜像）、Remotes 开关一键隐藏 origin/* badge
  （badge/tooltip/详情/搜索五处同步）、分支选择按仓库路径持久化（localStorage，
  空选择与换仓瞬态不写，重开自动恢复）
- 工程化：git 历史、基准仓库测试、mock.html 浏览器调试链

## M3 — 图即操作入口

目标：从"看历史"走到"在历史里干活"。

**定位决策（2026-08-29）**：gtv 保持只读，仅开两个例外——切换当前分支
（3.1，须带脏工作区确认）与分支/提交对比（3.2，纯读）。其余实质性写操作
（从节点建分支、merge、cherry-pick、rename/delete 等，原 3.3）**不做**。
多仓库标签页：先不做，等真实使用场景出现再立项。落地 3.1 时需同步放宽
README / AGENTS.md 的只读承诺措辞（"除显式 checkout 外不修改仓库"级语义）。

| # | 事项 | 说明 |
|---|---|---|
| 3.1 | 真实 checkout | switch_branch 后端已实现未接通；前端接通 + 脏工作区确认对话框 |
| 3.2 | **分支/提交对比** | Ctrl+点击多选两个节点（或两分支 tip）→ 详情面板切换为 diff 视图（gmaster 的 "diff selected changesets"）；分支对比复用同一 diff 通道（tip 对 tip） |
| 3.4 | 详情三栏联动 | 详情面板内嵌 diff 区（选中文件 → 行内 diff），而非只列文件名。纯读，不受只读决策约束 |

## M4 — 视觉语言升级

目标：信息编码更丰富，向原作的图形词汇靠拢但保持 gtv 自己的深色审美。

| # | 事项 | 说明 |
|---|---|---|
| 4.1 | 双线泳道 + 空心大圆节点 | branch-explorer-full.png 确认的原作词汇：泳道为双线横杠（活跃段实线/非活跃段虚线），节点大空心圆，选中态内填。提高泳道"实体感" |
| 4.2 | 节点状态编码 | 原作节点有"下半圆填色"（语义未考据确认）。gtv 自定义为：下半圆填色 = 该提交有未推送内容（ahead），或编码 CI 状态（远期） |
| 4.3 | HEAD 家形图标 | 文字 HEAD 标签升级为图标节点（原作做法），工作区有家时的隐喻 |
| 4.4 | ahead/behind 徽标 | 本地分支相对上游的领先/落后计数，显示在泳道芯片上 |
| 4.5 | 浅色主题 | 原作是浅色；gtv 纯深色。主题变量化后补一套浅色 |
